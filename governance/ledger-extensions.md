# Ledger extension identifiers

The identifiers under which other specifications name `ledger-1` extension kinds, `<identifier>/<name>` ([RFC 0014](../rfcs/0014-ledger-v1.md), section 5). Each is assigned once and never reassigned, so no two specifications claim one, and a key registered for one specification's kind is never read as another's.

**Assignment.** By the RFC that defines the specification, which adds its row when accepted, or by a pull request to this file that names the specification, decided under [RFC 0001](../rfcs/0001-standards-process.md). An identifier is 1 to 32 lowercase ASCII letters, digits and `-`, starting with a letter.

Nothing is assigned while RFC 0014 is a draft.
