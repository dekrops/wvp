# RFC NNNN: Title

|            |                                                             |
| ---------- | ----------------------------------------------------------- |
| RFC        | NNNN                                                        |
| Status     | Draft                                                       |
| Author     | Name                                                        |
| Created    | YYYY-MM-DD                                                  |
| Affects    | The specifications and versions this changes, by identifier |
| Supersedes | An RFC number, or nothing                                   |

One paragraph: what changes, and for whom.

## Motivation

The problem, stated so that someone who disagrees with the solution agrees there is a problem. Link the issue, the reproduction, or the implementer's report.

## What changes

The change, precisely enough to implement. Not specification text: say what the text will define.

## Outcomes that change

Every input whose outcome differs from today, or "none". If any does, this is a new version ([RFC 0001](0001-standards-process.md), section 6): name its identifier.

## Compatibility

What an existing producer, verifier and relying party must do, and what happens if they do nothing.

## Vectors

The cases the corpus will gain, the refusals among them.

## Security considerations

Required if the RFC touches anything in RFC 0001 section 9.1; otherwise say why it does not. What an adversary controls, what this prevents, what it does not.

## Formal semantics

What is proved, what is tested, and what neither covers.

## Alternatives

What else was considered, and why not.

## Open questions

What is not decided.

## Decision

Written by the maintainers: accepted or rejected, the reasons, the objections not adopted and the answer to each, who reviewed it, and whether anyone outside the steward did.

## Implementation

Filled in later: the specification, version and commit that carry it out, and the implementations that reproduce its vectors.
