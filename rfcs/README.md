# RFCs

How the protocol changes. [RFC 0001](0001-standards-process.md) is the process; start there.

| RFC                                                 | Title                               | Status   |
| --------------------------------------------------- | ----------------------------------- | -------- |
| [0001](0001-standards-process.md)                   | The WVP standards process           | Accepted |
| [0003](0003-wvp-0.3.md)                             | WVP v0.3                            | Draft    |
| [0004](0004-conformance-profiles.md)                | Conformance profiles                | Draft    |
| [0002](0002-inputs-every-verifier-refuses-alike.md) | Inputs every verifier refuses alike | Draft    |

To propose a change, copy [the template](0000-template.md) to `NNNN-short-title.md`, using the next free number, and open a pull request. A question or an ambiguity does not need an RFC: open an issue ([contributing](../CONTRIBUTING.md)).

[The open questions](../governance/open-questions.md) list the RFCs the protocol is known to need.
